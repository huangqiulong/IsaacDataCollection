## Overview

The race in robot learning is shifting from *models* to *data*. This repository documents a complete, practical route for collecting training data inside the **Isaac Sim simulator**:

- **A tour of five data-collection paradigms**: teleoperation, motion capture (mocap), UMI, EGO, and simulation-first generation (Mimic / RL / SDG) — plus a dimension-by-dimension comparison with real-robot collection;
- **Reproducible hands-on guides**: from a cold start, teleoperate a Franka arm to stack three cubes using keyboard / Xbox controller, and record HDF5 demonstration datasets;
- **A full data loop**: seed demos → Mimic augmentation → behavior cloning (BC) training → success-rate evaluation, with measured numbers at every step;
- **Deep dives into the data format**: HDF5 structure, time-alignment relationships, quaternion order conventions, processing recipes and pitfalls (96-byte truncation, merge fix-ups, etc.).

Everything has been validated hands-on: 3 keyboard demos (2,780 steps), Mimic scaling 30 seeds into **300 demonstrations (237k frames)**, BC success rate improving from **1/20 to 5/20**, real mocap data visualizations, and more.

## Companion Scripts

| Script | Purpose |
| --- | --- |
| `scripts/teleop_dataset_stats.py` | Dataset statistics & quality check (steps / jerk / gripper toggles, no Isaac required) |
| `scripts/hdf5_plot_demo.py` | Per-demo curve visualization (actions / joints / end-effector trajectory) |
| `scripts/merge_teleop_datasets.py` | Merge multiple datasets (per-episode copy + renumbering, verified lossless) |
| `scripts/bc_eval_diagnose.py` | BC policy rollout diagnostics (approach distance / stack height per segment) |
| `scripts/isaaclab_teleop_launch.py` | Launcher enabling gamepad recording (registers `-Teleop` task variants, upstream repo untouched) |

| `scripts/isaac_sim_01~04_figures.py` | Figure generators for the whole blog series (matplotlib + graphviz) |

## Quick Start

Prerequisites: a machine with Isaac Sim / Isaac Lab installed. The utility scripts themselves only need Python with `h5py` / `numpy` / `matplotlib`; the figure generators additionally require `graphviz`.

```bash
# 1) Dataset quality check (replace the HDF5 path with yours)
python scripts/teleop_dataset_stats.py ~/code/isaac/IsaacDataCollection/datasets/dataset_gamepad.hdf5

# 2) Visualize a single demonstration
python scripts/hdf5_plot_demo.py ~/code/isaac/IsaacDataCollection/datasets/dataset_gamepad.hdf5 --demo demo_1

# 3) Regenerate blog figures
python scripts/isaac_sim_01_figures.py              # all figures
python scripts/isaac_sim_01_figures.py --only fig4  # a single figure
```

> For the full teleop / Mimic / training commands, see blog posts (2) and (4).
